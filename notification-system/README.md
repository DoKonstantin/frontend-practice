# 📱 Modal Window (Notification System)

Simple JavaScript project that demonstrates a clean and accessible modal window implementation.

## 🚀 Features

- Smooth open/close animations (fade + scale transitions)
- Background scroll lock when modal is open
- Close modal with Escape key
- Optional click on overlay to close (commented in code)
- Responsive design for all screen sizes
- Pure vanilla implementation (no dependencies)

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)

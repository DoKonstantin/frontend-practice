# 🔒🔑 Password Generator

Simple JawaScript project that generates secure passwords.

## 🚀 Features

- Adjustable password length (8-18 characters)
- Uppercase, lowecase, numbers and symbal support
- Guaranteed character inclusion per selected type
- Password strength indicator
- Copy password to clipboard
- Responsive layout

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript (Vanila)

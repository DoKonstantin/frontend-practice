
# 📃 Tab Component

Simple JavaScript project with a tabbed interface.

## 🚀 Features

- Three tabs: About, Features, Contact
- Tab switching with JavaScript
- Active tab and content highlighting
- Smooth hover animations (lift effect + shadow)
- Responsive layout — tabs stack vertically on mobile (≤360px)
- Clean, warm color palette

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)
